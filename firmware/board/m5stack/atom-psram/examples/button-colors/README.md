# M5Atom button colors on Atom-PSRAM

The K115 has one RGB pixel on GPIO27. It displays pixel 0 of the upstream 5×5 Matrix example. After the initial red, successive debounced GPIO39 presses show dim red, green, blue and white. Hold or release leaves the current color in place. No external accessory is required.
