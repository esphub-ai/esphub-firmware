# Scales Kit

Connect Unit Weight U030 to the K115 host Grove port. GPIO32 reads HX711 DOUT and GPIO26 drives SCK. Remove any load before boot. The onboard pixel shows red during startup calibration, green for measurements, and blue while taring. Press GPIO39 to tare again. The original 27.61 counts per gram is an example calibration factor for the kit. Output is in kg.
